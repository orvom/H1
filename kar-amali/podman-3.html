کتاب: «حسابداری تهیه و تنظیم صورت‌های مالی» (کد ۲۱۲۲۵۴). ارقام به ریال است مگر جایی که نوشته شده.

یادآوری: معادله‌ی حسابداری دارایی‌ها = بدهی‌ها + سرمایه. دارایی جاری یعنی طی ۱۲ ماه (یا یک چرخه‌ی عملیاتی) به نقد تبدیل می‌شه یا مصرف می‌شه؛ بدهی جاری یعنی طی ۱۲ ماه (یا چرخه‌ی عملیاتی) باید تسویه بشه. هر ترازنامه‌ای که این‌جا حل شده با برنامه چک شده که جمع دارایی‌ها = جمع بدهی‌ها و سرمایه.

کار عملی ۱ · تغییرات دارایی، بدهی و سرمایه (مؤسسه بروجن)

صورت مسئله: تغییرات سالانه‌ی دارایی‌ها، بدهی‌ها و سرمایه (هزار ریال) با چند مجهول داده شده؛ مجهول‌ها مشخص شود.

ایده: معادله‌ی حسابداری در هر سال برقراره، پس تغییرات هم همین رابطه رو دارن: تغییر دارایی = تغییر بدهی + تغییر سرمایه.

سال تغییر دارایی‌ها تغییر بدهی‌ها تغییر سرمایه
۱۳۹۳ +۱٬۵۰۰٬۰۰۰ +۱٬۱۲۰٬۰۰۰ +۳۸۰٬۰۰۰ ✅
۱۳۹۴ −۱٬۶۰۰٬۰۰۰ ✅ −۲٬۲۱۰٬۰۰۰ +۶۱۰٬۰۰۰
۱۳۹۵ −۱٬۰۳۸٬۰۰۰ ✅ −۱٬۹۵۰٬۰۰۰ +۹۱۲٬۰۰۰
۱۳۹۶ +۴۲۵٬۰۰۰ +۳۴۲٬۵۰۰ ✅ +۸۲٬۵۰۰

(✅ = مقدار محاسبه‌شده.) مثلاً ۱۳۹۳: سرمایه = ۱٬۵۰۰٬۰۰۰ − ۱٬۱۲۰٬۰۰۰ = ۳۸۰٬۰۰۰؛ ۱۳۹۴: دارایی = (−۲٬۲۱۰٬۰۰۰) + ۶۱۰٬۰۰۰ = −۱٬۶۰۰٬۰۰۰؛ ۱۳۹۶: بدهی = ۴۲۵٬۰۰۰ − ۸۲٬۵۰۰ = ۳۴۲٬۵۰۰.

کار عملی ۲ · موجودی نقد

صورت مسئله: با این اقلام مانده‌ی «موجودی نقد» مؤسسه را مشخص کنید: چک رمزدار (بین‌بانکی) ۶۱٬۰۰۰٬۰۰۰ · سپرده ۶ ماهه نزد بانک ۶۰٬۰۰۰٬۰۰۰ · سکه و اسکناس ۱۰٬۰۰۰٬۰۰۰ · تنخواه‌گردان ۱۰٬۰۰۰٬۰۰۰ · سپرده بانکی ۲ ساله ۴۰٬۰۰۰٬۰۰۰ · حساب جاری نزد بانک ۲۰٬۰۰۰٬۰۰۰ · وجوه پیش‌پرداخت‌شده برای خرید اموال ۳۵٬۰۰۰٬۰۰۰.

موجودی نقد = ۱۰٬۰۰۰٬۰۰۰ + ۱۰٬۰۰۰٬۰۰۰ + ۲۰٬۰۰۰٬۰۰۰ + ۶۱٬۰۰۰٬۰۰۰ = ۱۰۱٬۰۰۰٬۰۰۰ ریال.

نکته: چک رمزدار (بین‌بانکی) رو مثل وجه نقد حساب کردم چون هر لحظه قابل تبدیله و محدودیتی نداره. کتاب «سپرده‌های سرمایه‌گذاری بدون سررسید» رو جزو وجه نقد می‌دونه، سپرده‌ی ۶ ماهه سررسید داره پس نقد نیست.

کار عملی ۱۲ · تکمیل ترازنامه‌ی ناقص (مؤسسه بلوچستان)

صورت مسئله: ترازنامه (به صدهزار ریال) چند جای خالی داره؛ با «سایر اطلاعات» (۱. سرمایه ۱۳۹۶ نسبت به ۱۳۹۵ ده درصد رشد؛ ۲. در ۱۳۹۵ دارایی غیرجاری دو برابر جاری؛ ۳. سایر دارایی‌های ۱۳۹۶ یازده درصد بیشتر از سال قبل) کامل شود.

مسیر حل (مرحله به مرحله):

  1. برچسب‌های خالی با ترتیب ثابت ترازنامه پر می‌شن: بعد از دریافتنی‌ها ← «موجودی مواد و کالا»؛ اولین قلم غیرجاری ← «دریافتنی‌های بلندمدت»؛ بعد از نامشهود ← «دارایی‌های ثابت مشهود»؛ آخر بدهی جاری ← «بدهی‌های مرتبط با دارایی‌های نگهداری‌شده برای فروش»؛ آخر بدهی غیرجاری ← «ذخیره مزایای پایان خدمت». (مبلغ‌های اون ردیف‌ها خودشون داده شدن.)
  2. جمع دارایی‌های جاری ۱۳۹۵ = ۸٬۲۹۸ + ۱۳٬۹۰۵ + ۳۵٬۰۱۰ + ۹٬۴۵۰ + ۱٬۲۸۷ + ۱۱٬۱۶۰ = ۷۹٬۱۱۰. طبق اطلاعات ۲: دارایی غیرجاری ۱۳۹۵ = ۲ × ۷۹٬۱۱۰ = ۱۵۸٬۲۲۰ ← جمع دارایی‌ها ۱۳۹۵ = ۲۳۷٬۳۳۰.
  3. سایر دارایی‌ها ۱۳۹۶ = ۲٬۰۰۰ × ۱٫۱۱ = ۲٬۲۲۰.
  4. دارایی غیرجاری ۱۳۹۶ = ۱۹۷٬۳۴۰ داده شده؛ دریافتنی بلندمدت ۱۳۹۶ = ۱۹۷٬۳۴۰ − (۲۱٬۲۳۰ + ۶٬۶۰۰ + ۲٬۷۵۰ + ۱۴٬۵۴۰ + ۲٬۲۲۰) = ۱۵۰٬۰۰۰.
  5. سرمایه‌گذاری بلندمدت ۱۳۹۵ = ۱۵۸٬۲۲۰ − (۱۵٬۹۴۰ + ۴٬۹۵۰ + ۲٬۱۰۰ + ۱۱۵٬۲۰۰ + ۲٬۰۰۰) = ۱۸٬۰۳۰.
  6. تسهیلات مالی (جاری) ۱۳۹۵ = ۳۷٬۱۸۰ − (۳٬۸۷۰ + ۹۰۰ + ۶٬۱۷۵ + ۷٬۳۳۵ + ۱٬۳۵۰) = ۱۷٬۵۵۰.
  7. سرمایه ۱۳۹۵ = جمع دارایی‌ها − بدهی‌ها − سود انباشته = ۲۳۷٬۳۳۰ − ۹۴٬۲۷۰ − ۲۵٬۰۶۰ = ۱۱۸٬۰۰۰ ← سرمایه ۱۳۹۶ = ۱٫۱ × ۱۱۸٬۰۰۰ = ۱۲۹٬۸۰۰.
  8. پرداختنی بلندمدت ۱۳۹۶ = ۳۰۸٬۴۴۰ − (۴۹٬۷۴۲ + ۲۳٬۳۲۰ + ۳۸٬۶۷۶ + ۱۲۹٬۸۰۰ + ۵۱٬۴۰۳) = ۱۵٬۴۹۹.
